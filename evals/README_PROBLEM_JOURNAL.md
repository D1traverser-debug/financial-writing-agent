# Problem Journal Discovery Pointer

For maintenance history and later total-controller guidance, read in this order:

1. `evals/PROBLEM_EVOLUTION_JOURNAL_INDEX.json` — machine-readable current open/problem-guidance pointers.
2. `evals/PROBLEM_EVOLUTION_JOURNAL.md` — chronological problem + repair-history ledger.
3. `evals/PARENT_GUIDANCE_HANDOFF.md` — non-mutating Financial -> UAOS guidance queue.
4. linked detailed incident/eval files for primary evidence.

The journal is evidence/history only. Current business authority remains the current Financial product/rule/state surfaces.

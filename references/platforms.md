# Platform adaptation

This file owns **distribution mechanics**, not generic writing method. Headline craft, hooks, structure and information density remain owned by the editorial module.

## Finance communities

Typical targets: Xueqiu, Jiuyangongshe and Eastmoney-style finance communities. Default to `FINANCE_DEEP`: retain the industry transmission chain, company-universe competition, market-selection logic and verification points.

## Broad-distribution platforms

Typical targets: Toutiao, Baijiahao, NetEase-style distribution and similar feeds. Default to `FINANCE_BROAD`: still write a financial article, but frame the topic so finance users outside the specific sector can see the investment relevance.

## Platform data

Treat platform algorithms as changing external systems. Before using a platform-specific rule, prefer current official documentation and the account's own recent performance data. A single viral or failed article is an experience sample, not a permanent rule.

Separate:
- distribution/recommendation signals;
- search/long-tail signals;
- article quality signals;
- the account's own observed performance.

Do not let a platform method redefine the core editorial method.

## 1. 核心判断

中国冰雪经济已经跨过“冬奥后是否还能增长”的验证阶段，进入“万亿规模之后如何提高单位客流价值、延长经营季、向南方与室内场景扩散、让装备和服务形成持续收入”的阶段。真正重要的变化不是单纯游客更多，而是供给和变现路径开始分层：

1. **目的地经济**：自然雪资源与品牌目的地通过交通、索道、门票、酒店、餐饮、温泉、夜游和二消提高客单价，并通过夏季项目降低季节性。
2. **室内与场馆经济**：室内真雪场增长，使冰雪消费从北方自然雪季向南方城市和四季化供给扩散，带动制冷、造雪、节能控制、工程建设等需求。
3. **装备与品牌消费**：参与人群扩大后，增量从“第一次体验”向服装、鞋品、雪具、专业功能装备与社群消费迁移；但上市公司通常不单独披露滑雪收入，不能把全部户外增长归因于冰雪。
4. **政策只是需求底座，不是利润保证**：项目周期、天气、客流结构、竞争、原材料、品牌效率和资本开支决定最终盈利。2026年半年报已经显示同一主题内公司业绩分化明显。

## 2. 宏观与政策证据

### 2.1 规模已经跨过万亿元

国家体育总局冬季运动管理中心披露，2025年中国冰雪经济总规模首次突破1万亿元。2025—2026冰雪季，全国居民冰雪运动参与人数达3.08亿，参与率21.75%，冰雪运动消费规模约2050亿元，同比增长约9.3%。

同一报告显示，冰雪场地供给正在结构化变化：正常运营滑雪场894家，室内真雪场86家。结合上一雪季国家体育总局披露的79家室内滑雪场，可以把“室内化、南方化、四季化”视为供给端的重要方向，但不能把场馆数量增长直接等同于盈利增长。

来源：国家体育总局，《冰雪经济总规模2025年破万亿》，2026年。
https://www.sport.gov.cn/n20001280/n20745751/c29844749/content.html

### 2.2 政策目标仍提供中期产业空间

国务院办公厅《关于以冰雪运动高质量发展激发冰雪经济活力的若干意见》提出：到2027年冰雪经济总规模达到1.2万亿元，到2030年达到1.5万亿元，并明确以冰雪运动为引领，带动冰雪文化、冰雪装备、冰雪旅游全产业链发展。

来源：中国政府网，国办发〔2024〕49号，2024-11-06。
https://app.www.gov.cn/govdata/gov/202411/06/521379/article.html

### 2.3 旅游仍是最大的消费入口之一

中国旅游研究院发布的《中国冰雪旅游发展报告（2026）》预计，2025—2026冬季我国冰雪旅游休闲人数将达3.6亿人次、收入4500亿元，其中以冰雪旅游为主要出游动机的游客预计2.2亿人次。

来源：文化和旅游部网站，2026-01-06。
https://www.mct.gov.cn/wlbphone/wlbydd/xxfb/qglb/hlj/202601/t20260106_964012.html

**口径边界**：不同年度报告中的“冰雪运动参与人数”“冰雪旅游休闲人数”“以冰雪为主要动机游客”并非同一统计对象，因此不能直接做同比或简单相减。文章只使用各自口径内的规模判断，不伪造统一增长率。

## 3. 经济传导链

### 3.1 目的地与景区

冰雪参与/旅游需求上升 → 景区客流 → 交通/索道/门票 → 酒店餐饮温泉/夜游等二次消费 → 淡季项目补充 → 年度收入与利润。

关键敏感项：雪季长度、极端天气、运力、客房与餐饮供给、客单价、二消率、固定成本和淡季利用率。

### 3.2 场馆与制冷设备

室内雪场/冰场和存量场馆升级 → 设计与工程订单 → 制冷/造雪/控制系统设备 → 交付确认收入 → 毛利率与回款。

关键敏感项：项目开工与验收节奏、原材料、行业竞争、客户付款能力、工程现金流。行业扩容不等于设备企业利润同步上升。

### 3.3 户外与滑雪装备

参与人数扩大 → 入门体验 → 复购与专业化 → 功能服装/鞋品/雪具/配件 → 品牌溢价、渠道效率与会员复购。

关键敏感项：品牌力、产品结构、直营/经销效率、库存、折扣、天气与赛事社群运营。多数公司不单列滑雪品类收入，因此只能证明“冰雪是户外消费的一个增量场景”，不能把全部户外业绩归因于冰雪。

## 4. A股 Universe Coverage Ledger

### Class A｜冰雪目的地与景区运营

#### 长白山（603099）— `MATERIAL`
- 经济角色：长白山目的地交通、酒店、温泉、旅行社等运营，冰雪资源与冬季旅游直接相关。
- 2025年年报披露长白山景区游客367.73万人次，同比增长7.9%；冬季围绕“粉雪”打造多个冰雪体验项目与度假线路。
- 2026年上半年营业收入2.77亿元，同比增长17.74%；归母净利润126.85万元，同比扭亏。半年度仍受季节性影响，不能把上半年微利外推为全年高利润。
- 判断：是目的地类最直接的上市公司样本之一，核心变量是客流、二消与全年经营季延长。
- 来源：长白山2025年年度报告；上交所2026年半年度报告公告；中国证券报中报数据。

#### 天府文旅（000558）— `MATERIAL`
- 经济角色：控股子公司围绕西岭雪山经营索道、滑雪、酒店、娱乐等业务。
- 2025年西岭雪山接待游客76.62万人次，同比增长1.49%；雪季建设约1.8万平方米地形公园并推动夜游/夜滑，4—11月增加水上和山地项目，夏季游客同比增长46.5%，是“四季运营”非常典型的案例。
- 2026年上半年营业收入1.41亿元，同比下降31.11%，归母净亏损2106.6万元；公司披露的重要原因之一是暖冬导致雪季较短、客流下降。
- 判断：最能说明“冰雪需求增长 ≠ 个股利润线性增长”，天气和固定成本会放大业绩波动。
- 来源：2025年年度报告：https://static.cninfo.com.cn/finalpage/2026-04-23/1225155451.PDF
- 2026年半年度报告摘要：https://static.cninfo.com.cn/finalpage/2026-08-26/1225500704.PDF

#### 西域旅游（300859）— `SECONDARY`
- 经济角色：天山天池客运、索道、游船、温泉酒店等综合文旅；冬季有冰上娱乐和温泉场景，但冰雪并非单一主营。
- 2026年上半年营业总收入1.07亿元，同比下降6.08%；归母净利润367.91万元，同比下降67.23%。
- 判断：具备新疆冰雪旅游映射，但冰雪收入拆分不足，不列为“纯冰雪运营商”。
- 来源：西域旅游2026年半年度报告：https://static.cninfo.com.cn/finalpage/2026-08-18/1225477040.PDF

### Class B｜冰雪场馆、制冷与造雪设备

#### 冰山冷热（000530）— `MATERIAL`
- 经济角色：完整冷热产业链，历史上服务冰场制冰制冷控制系统，年报明确关注冰雪场馆建设需求。
- 2026年上半年营业收入21.80亿元，同比下降8.62%；归母净利润4714.26万元，同比下降39.98%，公司解释主要受原材料价格上涨和市场竞争加剧影响。
- 判断：行业场馆扩容能带来项目机会，但设备企业兑现取决于订单、毛利和交付；当前利润表现正好构成反证。
- 来源：2026年半年度报告：https://static.cninfo.com.cn/finalpage/2026-08-13/1225470282.PDF

#### 雪人集团（002639）— `MATERIAL`
- 经济角色：制冷设备、压缩机与Snowkey等系统覆盖人工冰雪/冰雪运动场景。
- 2026年上半年营业总收入12.25亿元，同比增长27.60%，归母净利润618.87万元，同比下降76.99%，扣非净利润亏损136.53万元。
- 判断：收入增长与利润下降并存，进一步说明冰雪设备主题不能只看订单/收入，还要看成本、产品结构和现金流。
- 来源：雪人集团2025年年度报告、2026年半年度报告公开披露；中国证券报2026-08-24中报数据。

#### 冰轮环境（000811）— `REFERENCE_ONLY`

- 排除原因：本轮未取得足够强的当期“冰雪场馆/人工造雪”收入或项目证据，不能仅凭制冷标签进入核心受益名单。

### Class C｜户外与滑雪装备/品牌消费

#### 三夫户外（002780）— `MATERIAL`
- 经济角色：专业户外零售与品牌运营，门店有滑雪装备专区，品牌矩阵覆盖多类雪具/户外品牌。
- 2025年X-BIONIC收入约3.94亿元，同比增长约35.85%；公司整体2025年营收9.56亿元，同比增长19.41%，归母净利润5335万元，同比增长348.21%。
- 2026年上半年继续保持较快增长，但公司没有把“滑雪收入”作为独立分部披露。
- 判断：可作为户外消费升级样本，但必须把“户外品牌增长”与“纯冰雪贡献”分开表达。
- 来源：2025年年度报告：https://static.cninfo.com.cn/finalpage/2026-04-29/1225244383.PDF；2026年半年度报告：https://static.cninfo.com.cn/finalpage/2026-08-29/1225533152.pdf

#### 探路者（300005）— `SECONDARY`
- 经济角色：户外产品覆盖登山、徒步、滑雪、露营等场景。
- 2026年上半年总营收9.29亿元，同比增长42.34%，归母净利润5125.31万元，同比增长155.06%；但户外业务收入约5.71亿元，同比增长6.05%，集团高增长受芯片资产并表和业务结构变化明显影响。
- 判断：不能把集团层面的高增长作为冰雪经济兑现证据；更适合说明专业户外渗透而非纯冰雪弹性。
- 来源：探路者2026年半年度报告公开披露。

## 5. 两轮研究覆盖记录

### Sweep A｜政策、行业规模、消费与场地供给
- 来源角度：国务院政策、国家体育总局、文化和旅游部/中国旅游研究院。
- 新增信息：万亿规模、3.08亿参与人数、2050亿元运动消费、2027/2030政策目标、3.6亿冰雪旅游休闲人次与4500亿元预计收入、室内真雪场扩张。

### Sweep B｜公司价值链与最新经营兑现
- 来源角度：上市公司2025年年报、2026年半年报、交易所/巨潮披露。
- 新增信息：目的地运营、场馆设备、户外品牌三条不同盈利链；2026年中报显示同一冰雪主题下长白山改善、天府文旅受暖冬冲击、冰山冷热和雪人集团利润承压、探路者集团增长不能归因于滑雪。

### Stop reason
第二轮没有发现必须新增的第四个核心价值链类别；新增候选主要落入普通旅游、普通制冷或体育概念邻接，缺乏足够强的冰雪业务证据。继续无限扩展公司名单会降低证据质量。保留的主要缺口是：多数公司未单独披露冰雪业务收入/利润，无法进行精确的冰雪收入贡献排序。

## 6. 反证与风险

1. **天气风险**：暖冬可直接缩短自然雪场经营季；天府文旅2026H1即是现实案例。
2. **季节性与固定成本**：景区、索道、酒店和雪场固定资产重，客流波动会放大利润弹性。
3. **项目兑现风险**：冰雪场馆建设需要经历招标、施工、验收、回款，政策目标不能直接变成当期收入。
4. **设备利润风险**：原材料与竞争可侵蚀毛利，冰山冷热、雪人集团2026H1都显示收入/利润并非同步。
5. **概念归因风险**：户外、文旅、制冷公司的非冰雪业务可能占大头；探路者2026H1集团增长就明显受芯片业务影响。
6. **数据口径风险**：旅游人次、运动参与人数、滑雪场客流等口径不同，不做伪同比。

- 信息差3：同一个冰雪主题存在三种完全不同的赚钱方式，因此公司业绩会严重分化。

## 8. 结论

冰雪经济的下一阶段不是“有没有人去滑雪”，而是“3亿级参与人群能否被持续转化为全年消费、专业装备复购、目的地二消和场馆投资”。对于A股研究，最重要的不是扩张概念股名单，而是把每家公司放回真实的收入确认链条：客流型看雪季与客单，工程型看订单与毛利，品牌型看品类渗透和渠道效率。只有这样，万亿产业规模才可能被转换成可验证的上市公司业绩判断。

# EDITORIAL — 跨境电商

Task: `cross-border-ecommerce-20261015`
Stage: `EDITORIAL`
Distribution: `PORTFOLIO`

## Topic DNA

- New fact: 2026 年跨境电商总量仍扩张，但美欧低值进口规则与平台/产品合规同步升级，A 股半年报已经出现渠道、品类、履约与基础设施之间的明显分化。
- Main transmission: 低值免税/低价直邮优势收缩 → 单件履约/合规/关税成本抬升 → 卖家调整产品、渠道与库存布局 → 本地履约/B2B/品牌与精品能力的重要性上升 → 支付/营销/合规/物流等基础设施需求增加 → 最终由单位经济性、库存周转、平台费和汇率决定利润兑现。
- Likely reader misjudgment: 看到“海外仓出口+3.3倍”就直接买海外仓逻辑，或看到 Temu 渠道收入下滑就断言平台退潮；这些都把价值链的一段当成整条利润链。
- Comparison dimensions: 品牌/产品毛利、泛品与精品结构、平台集中度及单位经济性、B2C/B2B结构、本地库存与履约、广告/平台费/关税吸收能力、汇率、合规、现金流。
- Finance-wide question: 当政策红利从“包裹”层退出后，跨境电商的超额利润到底转移到哪里？

## Candidate A — 利润池迁移全链条
Rationale: 从政策与成本结构切入，先解释为什么总量增长与公司分化可以同时成立，再把卖家、B2B、本地履约和基础设施放进同一利润传导框架。最符合 Deep 的完整判断需求。

Sections:
1. 行业没有退潮，旧的低门槛利润在退潮
2. 低值小包规则变化如何穿透到卖家利润表
3. 为什么 A 股卖家已经分成三类：品牌/精品、平台型经营、B2B/本地化
4. 海外仓不是简单受益：量增长与公司利润之间还隔着利用率、尾程、库存和汇率
5. 第二利润池：支付、B2B平台、营销、合规这些基础设施谁更容易兑现
6. 公司比较：安克、赛维、华凯、致欧、乐歌、三态、焦点、拉卡拉的暴露与差异
7. 未来验证：哪些指标证明利润池真的继续迁移，哪些变化会推翻当前判断

## Candidate B — 公司分化倒推产业链
Rationale: 先从安克增长、华凯泛品收缩、赛维 Amazon 增长、乐歌海外仓收入下降等反常数据切入，再倒推政策和利润池迁移，阅读冲击力更强但宏观因果顺序稍弱。

Sections:
1. 同一个“跨境电商”，半年报已经走出几种完全不同的结果
2. 分化背后的共同变量：小包、渠道、库存、品牌、汇率
3. 低价直邮红利退潮以后，谁获得新门槛
4. 海外仓与卖水人为什么也不是稳赚
5. 公司决策地图与后续验证

## Candidate A — 三个反常识数字
Rationale: 用“行业还在涨 / 海外仓量暴增但公司收入不涨 / Temu下滑而Amazon仍增长”三个冲突推动阅读，最后给出“利润池迁移”的解释。

Sections:
1. 跨境电商没退潮，但最容易赚的钱变了
2. 海外仓出口+3.3倍，为什么乐歌海外仓收入还下降
3. Temu渠道大降，为什么赛维Amazon还能增长
4. 钱最后流向哪里：产品/品牌、B2B、本地履约和卖水人
5. 最后看什么：毛利、库存、汇率、渠道单位经济性

Core contradictions:
- 行业规模扩张 vs 部分卖家/渠道收入收缩
- 海外仓宏观量暴增 vs 单家公司海外仓收入不增
- Temu渠道下滑 vs Amazon高集中卖家仍增长

Compression candidates:
- 完整进口跨境电商链只保留一句边界，不展开。
- 易点天下/蓝色光标/华贸物流按“基础设施对照”压缩，不逐家公司展开。
- 复杂 DSA 处罚细节压缩成规则趋严证据，不做法规科普。

## Candidate B — “3欧元”改变什么
Rationale: 用欧盟低值进口3欧元临时关税作为硬钩子，解释单件成本为何迫使商业模式变化。但容易过度聚焦欧洲而弱化美国和公司分化。

Sections:
1. 一件150欧元以下商品多3欧元，真正改变的是谁的生意
2. 低价直邮为什么最敏感
3. 本地库存/B2B/品牌为什么更有价值
4. A股半年报已经给出的三组分化

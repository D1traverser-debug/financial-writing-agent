# EDITORIAL

## TopicDNA
真正变化：白酒大商的渠道资产开始迁向黄酒，高端黄酒首次获得成体系的高端酒销售基础设施。
经济传导：白酒渠道利润收缩 → 大商寻找新利润品类 → 黄酒高毛利/价格空白承接 → 高端场景渗透 → 若复购成立则转化为中高端收入与全国化。
最大误判：把“千元定价/大商签约”直接等同于“高端需求成熟”。
核心公司差异：会稽山结构升级与省外扩张证据最强；古越龙山高端系列增长但转型任务更宽；金枫酒业作为反例说明非普惠。

## Candidate structure A（采用）
1. 白酒大商为何转黄酒：渠道利润与闲置资产。
2. 千元价格带与上桌权：高价产品 + 大商迁移。
3. 上市公司数据分化：会稽山/古越龙山/金枫酒业。
4. 第二阶段难点：价值标准、真实动销、全国化。
5. 三条验证线：渠道质量、高端收入/价盘、全国化消费。

## Candidate structure B（未采用）
从1959元价格锚点切入 → 高端标准 → 公司产品矩阵 → 渠道大商 → 风险。未采用原因：容易把“价格”误写成主因，削弱本题最有价值的渠道迁移机制。
